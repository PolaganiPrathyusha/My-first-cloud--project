# AI-900 Day 4: Computer Vision on Azure

## 1. What is Computer Vision?
AI capability that enables machines to interpret and understand visual information from the world.

## 2. Azure AI Vision Services
- **Azure AI Vision**: Analyze images, OCR, object detection
- **Azure AI Video Indexer**: Extract insights from videos
- **Custom Vision**: Build custom image classification models

## 3. Common Use Cases
Image analysis, text extraction, facial detection, video analysis

## 4. Key Takeaway
Computer Vision helps apps "see". Azure provides pre-built APIs so we don't have to train models from scratch.
